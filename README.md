Machine learning model to predict pKa of a molecule given its SMILES using RDKit descriptors. 

The model uses a LightGBM architecture, trained on a curated pKa dataset from https://github.com/cbio3lab/pKa/tree/main.

"Repository of experimental curated pKa database for acid and basic compounds (no zwiterionic species). This database was additionally curated from the database deposited at https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/6A67L9."
